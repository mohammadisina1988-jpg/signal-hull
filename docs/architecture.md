# SignalHull: exact randomized postprocessing of a consensus channel

The deployment commits to one public report URL and raw SHA-256. Anyone compiles that report exactly once. The contract fetches its complete prose; leader and validators separately extract ten counts (two trial totals and eight signal counts). Validators re-fetch bytes, compare every count exactly and separately audit each full clause. Unknown counts remain explicit. Only this consensus result becomes the immutable empirical channel.

The channel has two input contexts, low/high, four output signals, red/blue/green/gray, and exactly twelve mutually exclusive, exhaustive observations in each context. A caller requests an emit-one response profile `(a/12,b/12)`. Those numbers are desired behavior, not reported observations. A signal filter is four rational probabilities r, one per observed signal, satisfying `counts_low · r = a`, `counts_high · r = b`, and `0 <= r <= 1`.

All sixteen deterministic filters give points in a two-dimensional response plane. Their convex hull is the attainable zonotope. An attainable target is decomposed into at most three hull vertices using exact integer barycentric weights. Those weights construct an executable rational probability for each of the four signals. An unattainable target returns a separating line: every deterministic filter is on one side, the request strictly on the other. Identical rows produce a diagonal segment, handled explicitly rather than dividing by a zero area.

Designs are appended once per requested integer profile. Feasible filters can be postprocessed again: a caller gives the probabilities of emitting one after binary output zero/one. Composition updates the four rational probabilities and target profile exactly, retaining parent index and depth. No new information can be introduced by that composition. Three layers and sixteen total design/composition records bound arithmetic and storage. Failed calls append nothing. Anyone can preview profiles without mutating state.

The contract owns acquisition, interpretation consensus, attainable-region compilation, constructive filters, impossibility witnesses and composition history. Clients own display and any actual signal acquisition/random sampling. The source owns the empirical observations. Hashes establish bytes, not identity or physical truth. The contract does not assert statistical generalization from twelve trials, execute a sensor, or supply a secure random sampler.

This is a randomized-channel construction primitive, not a graph update, auction, one-time service certificate or renamed language-inclusion registry. The mathematical tools are classical: [Coarse-graining and the Blackwell order](https://arxiv.org/abs/1701.07602). The contract implements a deliberately bounded binary-input, four-signal, binary-output case. Generic CLI transport/test bootstrap is reused under MIT; the channel mechanism and independent linear-feasibility oracles are specific to this repository.
