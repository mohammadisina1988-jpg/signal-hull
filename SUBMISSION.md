**Title:** SignalHull: Consensus randomized signal filter compiler

**Notes / Description** (943 characters):

SignalHull constructs randomized signal filters from consensus-interpreted reports. Leader and validators independently fetch the complete commit-pinned source, extract all ten trial/outcome counts, compare every value exactly and audit each full clause. Sixteen deterministic rules define an attainable response polygon. Feasible requests receive exact rational mixtures of at most three rules; impossible requests receive an integer separating line. Recorded filters support three postprocessing layers with parent provenance. Unknown counts block design. Four gasless StudioNet instances cover informative, noisy, uninformative and unresolved reports. All 33 finalized receipts and 27 previews pass independent linear-feasibility and full-state checks. The repo includes 117 direct tests, seven transport tests and source-bound receipts. Synthetic empirical counts demonstrate construction, not population accuracy or physical-sensor truth.
